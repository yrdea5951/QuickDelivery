# QuickDelivery — Front-End Demo

واجهة مستقلة لإنشاء طلب توصيل ومشاركة بيانات نقطة الاستلام والتسليم.

## التشغيل
1. فك ضغط المشروع.
2. افتح المجلد في VS Code.
3. افتح `index.html` في المتصفح أو استخدم Live Server.

## الملفات
- `index.html`: الصفحة والنموذج.
- `style.css`: التصميم المتجاوب.
- `script.js`: تفاعلات النموذج واختيار الموعد والتحقق وعرض التأكيد التجريبي.

## الحدود الحالية
هذه واجهة Front-End فقط. لا ترسل طلبات فعلية ولا تُنفّذ مدفوعات. البيانات التجريبية تُحفظ محليًا في LocalStorage على نفس المتصفح. الملفات المختارة لا يتم رفعها إلى خادم. يلزم Backend منفصل وقاعدة بيانات وصلاحيات وأمان ودمج دفع رسمي قبل الإطلاق.
